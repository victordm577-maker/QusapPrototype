# QUSAP - Development Rules

- Una tarea pequeña por solicitud.
- No modificar archivos ajenos a la tarea.
- No añadir mecánicas no solicitadas.
- No instalar paquetes sin autorización.
- No ocultar errores ni warnings.
- Explicar todos los archivos creados o modificados.
- No escribir código hasta recibir una tarea específica.
- Mantener el proyecto modular y fácil de probar.
- Probar en Unity antes de realizar un commit.
