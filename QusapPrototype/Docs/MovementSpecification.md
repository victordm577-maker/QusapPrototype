# QUSAP - Movement Specification

El movimiento del personaje debe incluir:

- Movimiento horizontal con aceleración y frenado.
- Cambio rápido de dirección.
- Control aéreo configurable.
- Salto de altura variable.
- Coyote time.
- Jump buffer.
- Caída más rápida que la subida.
- Cámara lateral.

Todos los valores importantes deben poder ajustarse desde el Inspector.

Aún no se implementarán dash, combate, armas ni multijugador.
